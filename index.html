Une vraie petite IA, exécutée dans ton navigateur.

WebLLM charge un modèle open source directement sur l'appareil. Il n'y a ni clé API ni abonnement à payer.

Le premier lancement télécharge le modèle et peut prendre du temps. Il faut un navigateur compatible WebGPU et suffisamment de mémoire. Le modèle est petit : il ne possède pas les capacités d'une grande IA comme ChatGPT.
